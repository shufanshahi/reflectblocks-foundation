# ReflectBlocks — M3.5 semantic canvas

Current build:

- Google Sign-In + SQLite identity
- Home, quick thought, save/history
- 60 curated journaling blocks in 10 categories
- free-positioned reflection blocks with answers
- effectively infinite pan/zoom canvas
- draw.io-style four-side connector dots
- directed semantic arrows with rich/custom relationship labels
- branching and feedback loops
- block/header dragging
- optional subtle sound effects
- optional, consented Gemini next-block suggestions
- persistent blocks, positions, ports, arrows, labels & answers.
- per-user ownership isolation.

See `M3_5_DRAWIO_AI_GUIDE.md` for integration and setup.
